## Level project

Build a **multi-panel analytics dashboard simulator** using local data and
modules. It should support filtering, derived metrics, saved views, deliberate
error states, and asynchronous loading simulation. Explain the closure,
promise, and memory decisions in a short project note.

The lesson files above are the required sequence; complete each challenge
before using AI to compare alternatives.
